# backlog — ведение задач

Бэклог — версионированная память задач. Всё через утилиту `agctl`.

## Когда создавать карточку

- пользователь дал задачу длиннее одного ответа → карточка;
- найден дефект, который сейчас не чинишь → карточка;
- идея улучшения → карточка (P3).

## Команды

    agctl backlog new --title "Название" --priority P2 --size M --desc "Зачем и что"
    agctl backlog list            # открытые, по приоритету
    agctl backlog top 3           # топ-3
    agctl backlog start <id>      # в работу (in-progress)
    agctl backlog note <id> "что выяснил"
    agctl backlog done <id>       # завершено (карточка уедет в backlog/done)
    agctl backlog cancel <id>
    agctl backlog check           # валидация формата

## Приоритеты и размеры

- P1 — срочно; P2 — важно (по умолчанию); P3 — когда-нибудь.
- S — меньше часа; M — полвечера; L — многоэтапно.

## Правила

- Один коммит — одна задача; сообщение коммита — про карточку.
- Журнал карточки дописывается только в конец (append-only).
- Закрытые карточки не удаляются никогда.
