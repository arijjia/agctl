## Описание
Упростить Кабинет до workspace-центричного: убрать поле «Подключение к agctl» (legacy кросс-серверного режима; по умолчанию текущий origin), убрать пункт навигации «Личный чат» (воркспейсы и есть личный чат) и вкладку «Проекты» (это те же воркспейсы). Оставить: красиво показанную роль, SSH-ключ для developer, заявки роли, настройки конкретного воркспейса. Developer дополнительно видит настройки разработчика: логи контейнера, стоп/старт runtime и прочее — developer = пользователь с большим набором настроек.
