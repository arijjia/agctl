# Правила работы в этом репозитории

Ты — агент этого рабочего места. Репозиторий — твоя долговременная память.

## Коммиты — всегда

- Делай коммиты после КАЖДОГО значимого изменения: `git add -A && git commit`.
- Делай это как можно чаще. Незакоммиченная работа считается потерянной.
- Формат сообщения: `<что сделано>` одной строкой, по-русски или по-английски.

## Бэклог — твоя задача-память

- В корне есть `backlog/` — карточки задач (формат v1). Новый workload,
  идея, найденный дефект → карточка.
- Используй утилиту `agctl` (она установлена в системе):

  agctl backlog new --title "Понятное название" --priority P2 --desc "зачем"
  agctl backlog list
  agctl backlog note <id> "что выяснил"
  agctl backlog done <id>

- Полный синтаксис: `agctl backlog help`.

## Скиллы — правь их сам

- В `skills/` лежат твои рабочие процедуры (SKILL.md). Если в ходе работы
  выяснил, как делать лучше, — обнови соответствующий скилл и закоммить.
- Новые повторяющиеся процедуры оформляй новыми скиллами.

## Стиль

- Работай в этом каталоге: он смонтирован в твою среду и переживает
  перезапуск контейнера.
- Не храни секреты в файлах репозитория. Токен провайдера тебе передан
  через окружение — используй его, но не записывай в файлы.
- Историю не переписывай: git-лог — твой журнал. Ошибка → новый коммит,
  а не правка старого.
