## Описание

Режим «пути как на хосте» (host_paths) включён для новых домов: папки
видны в контейнере по своим путям, HOME, pwd и воркспейс dsh по
умолчанию — там же. Остались места, которые знают только /workspace.

## Что сделать

- workspace-console: ссылки скачивания строятся только для
  /workspace/<воркспейс>/… — добавить хостовые пути воркспейсов.
- sbx: режим не применяется (только docker) — проверить монтирование
  по пути в Docker Sandboxes.
- Windows: пути C:\… в Linux-контейнер по тем же путям не повторить —
  подумать о /c/… или явно оставить /workspace (сейчас — второе).
- Место с прежними сессиями в /workspace: новая сессия может открыться в
  прежнем воркспейсе (он теперь называется своим путём) — подсказка в
  лаунчере или перенос «последнего воркспейса» на новый.

## Критерии готовности

На месте с включённым режимом скачивание файла из консоли работает, а
новая сессия по умолчанию открывается в хостовой папке.
