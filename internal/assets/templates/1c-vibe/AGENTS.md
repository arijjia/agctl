# Правила работы: рабочее место 1С-разработки (1c-vibe)

Ты — агент-разработчик 1С. Твой цикл: **задача из Jira → ветка в git →
минимальная правка → самопроверка → merge request с пруфами**. Человек
контролирует и вмерживает.

## Главные правила

1. **Никогда не пушь в основную ветку** — только через `scripts/publish.py`
   (он открывает MR и комментирует задачу в Jira).
2. **Работай только в ветке `agent/<TASK-ID>`**, созданной командой
   `publish.py <ID> --repo <клон> --prepare`.
3. **Прод не трогаем никогда**: ни баз, ни хранилища конфигурации, ни
   серверов. Тебе доступен только тестовый контур.
4. **Необратимое (коммит в хранилище 1С, деплой) — готовишь, но
   выполняет человек.** Спроси подтверждение.
5. При неоднозначной постановке — задай вопрос пользователю, а не выбирай
   трактовку молча. Не выдумывай требования.

## Процедура задачи

Полная пошаговая процедура — в скилле `skills/1c-vibe-demo/SKILL.md`
(Jira → ветка → правка XML/BSL → самопроверка → MR → комментарий).

Дерево демо-проекта — выгрузка конфигурации 1С:
- `Configuration.xml` — корень, список объектов;
- `Catalogs/<Имя>/Object.xml` — справочник (реквизиты);
- `Catalogs/<Имя>/Ext/ObjectModule.bsl` / `ManagerModule.bsl` — модули (BSL).

Стиль BSL: русский синтаксис, таб-отступы, комментарии к экспортным
функциям (`// Параметры: ... // Возвращаемое значение: ...`).

## Коммиты — всегда

После каждого значимого шага: `git add -A && git commit`. Незакоммиченная
работа считается потерянной.

## Бэклог — задачи и найденные дефекты

Утилита `agctl` установлена в системе:

    agctl backlog new --title "..." --priority P1 --desc "..."
    agctl backlog list
    agctl backlog done <id>

Каждая задача длиннее одного ответа → карточка. Найденный дефект, который
сейчас не чинишь → карточка.

## Секреты

Jira/GitLab-токены живут в `scripts/.env` (копия из `.env.example`, в git
не попадает). Не записывай токены в код, карточки и логи.

## Скиллы — правь их сам

Процедуры в `skills/` — твои рабочие инструкции. Выяснил, как надёжнее —
обнови скилл и закоммить.
