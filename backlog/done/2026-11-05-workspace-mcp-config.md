## Описание

Продолжение «возможностей воркспейса» (каталог пакетов + промт + компоненты,
2026-11-05). Владелец просил в консоли воркспейсов настраивать системный
промт, скиллы «и, может быть, MCP» — MCP отложен этой карточкой. Нужен
per-workspace список MCP-серверов: включение/выключение серверов из
платформенного каталога для конкретного воркспейса, без ручной правки dsh-конфига.

## План

1. Выяснить контракт dsh 0.2.x по MCP-конфигу сессии (settings vs project
   `.dsh/…`, горячая перезагрузка) — истина в живом проводе, не в догадках.
2. Каталог MCP-серверов (подмножество разрешённых платформой; секреты —
   через agctl secrets, не в воркспейсе).
3. Раздел «MCP» в консоли воркспейсов + пакеты каталога с `mcp`-компонентом.
4. Аудит включений; гард-тест на ручки.

## Критерии готовности

- В консоли воркспейса можно включить/выключить MCP-сервер; новая сессия
  воркспейса получает ровно выбранный набор.
- Секреты MCP не попадают в рабочее дерево и в журнал.

- 2026-11-13: Шаг 1 плана — контракт dsh 0.2.x по живому проводу (исходники dsh + живой ~/.dsh, только чтение): MCP-серверы сессии монтируются cordis-рядами плагина @deepseek-ai/dsh-mcp-client в агентской композиции; композиция собирается из пресетов <DSH_HOME>/.agent-presets/<id>/agent.cordis.yml (discovery перечитывает корни на каждый вызов, preset.yml = name/description); выбор пресета — при создании сессии. Project-scope конфига у dsh нет ⇒ per-workspace рычаг agctl — генерация пресета воркспейса.
