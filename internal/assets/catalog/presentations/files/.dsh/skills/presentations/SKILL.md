# presentations — презентации по шаблонам университета

## Шаблоны и инструмент

- `templates/Shablon_Siniy.pptx` — синий шаблон (ключ `blue`, по умолчанию).
- `templates/Shablon_bely.pptx` — белый шаблон (ключ `white`).
- Инструмент: `scripts/make_pptx.py` (python3 + python-pptx; если библиотеки
  нет: `pip3 install --break-system-packages python-pptx`).

В шаблоне три макетных слайда: титульный, контентный (шапка + линия + логотип)
и финальный «СПАСИБО ЗА ВНИМАНИЕ!». Скрипт клонирует контентный слайд под
каждую секцию плана — оформление остаётся ровно как в шаблоне вуза.

## Процедура

1. Продумай структуру: 5–9 секций; каждая — один слайд (одна мысль на слайд).
2. Запиши план в `presentation/plan.json` (схема ниже), тексты — коротко:
   заголовок до 60 знаков, 3–6 пунктов по ≤ 90 знаков.
3. Собери и сразу проверь результат:
   ```
   python3 .dsh/skills/presentations/scripts/make_pptx.py build \
     --plan presentation/plan.json --out presentation/<имя>.pptx
   python3 .dsh/skills/presentations/scripts/make_pptx.py inspect presentation/<имя>.pptx
   ```
4. Покажи пользователю путь к готовому `.pptx`; правки = правка плана и
   повторный `build` (файл пересобирается целиком, ручные правки pptx не нужны).

## Схема plan.json

```json
{
  "template": "blue",
  "title": "НАЗВАНИЕ РАБОТЫ",
  "subtitle": "подзаголовок (можно пусто)",
  "byline": "05.11.2026 / докладчик",
  "sections": [
    {"header": "ЗАГОЛОВОК", "subheader": "подводка",
     "body": ["пункт 1", "пункт 2", "пункт 3"]},
    {"header": "СЛЕДУЮЩИЙ СЛАЙД", "subheader": "",
     "body": "абзац без буллитов\nвторая строка"}
  ],
  "final": "СПАСИБО ЗА ВНИМАНИЕ!"
}
```

- `body` списком → строки с буллитами; строкой → абзацы как есть.
- Ключи `template`, `subtitle`, `byline`, `final` необязательны.
- План хранится рядом с декой: это источник правды для повторных сборок.

## Проверка перед сдачей

`inspect` должен показать: слайдов = секции + 2; на каждом слайде заполнен
заголовок; пустых «Текст текст» из шаблона не осталось. Если пользователь
просит конкретное число слайдов — сначала согласуй структуру секций.
