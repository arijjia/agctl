Первый публичный релиз agctl — рабочие места с агентом dsh на машине разработчика и сервер организации.

**Установка** (macOS, Linux; Windows — `install.ps1`):

```bash
curl -fsSL https://raw.githubusercontent.com/arijjia/agctl/main/bin/install.sh | sh
agctl dev up        # дом настроится сам, папка проектов — ~/src
```

**Локальный режим**

- Лаунчер: рабочие места — контейнеры со своими папками, образом и домашним каталогом dsh; пресеты MCP-серверов и скиллов; доступы в хранилище ОС; мост к хосту (открыть файл в редакторе и другие разрешённые команды).
- Пути как на хосте: агент видит папку проектов по тем же путям, что на машине.
- Своя папка dsh-home — git-репозиторий конфигурации агента; клон места; смена версии dsh с откатом.
- Доступы из переменных окружения: `agctl dev up` заполняет пустые (токены — в хранилище ОС).
- `agctl dev llm-check` — каждая модель профиля: отвечает ли и вызывает ли инструменты.

**Образы рабочего места**

- Слои от редких к частым: новая версия dsh — это только верхние слои.
- Раздел «Образы»: что внутри, чем отличаются, как каждый собирается (Dockerfile, аргументы, что качается из сети); скачать, пересобрать, удалить.
- Если образа нет в реестре — сборка на месте из контекста, встроенного в бинарь.

**Профили организаций** — данные, не код: бренд, модели и сабагенты на быстрых моделях, каталог образов и возможностей, наследование вариантов (`extends`), адреса по умолчанию.

**Сервер организации** (`agctl-server`): рантаймы docker, Kubernetes, ax.

Архивы: `agctl` — macOS, Linux, Windows (amd64, arm64); `agctl-server` — macOS, Linux; guest-бинари образа — Linux.
